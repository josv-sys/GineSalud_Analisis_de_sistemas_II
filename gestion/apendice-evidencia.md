## Repositorio con documentación versionada

Para la gestión documentada de cambios y el control de versiones de los entregables se utilizó
un repositorio Git alojado en GitHub:

<https://github.com/josv-sys/GineSalud_Analisis_de_sistemas_II>

El repositorio organiza la documentación del proyecto en archivos Markdown por sección
(`docs/`), la fuente del diagrama de casos de uso en PlantUML (`diagramas/`), las versiones
oficiales en PDF entregadas (`entregables/`) y los artefactos de gestión del proyecto
(`gestion/`). Cada modificación queda registrada mediante un *commit* con su autor, fecha y
descripción, lo que permite consultar el historial completo de cambios y comparar versiones.
Las versiones entregadas se identifican con etiquetas (*tags*) de Git y se describen en el
archivo `CHANGELOG.md`.

## Tablero Kanban

La organización del trabajo se gestionó mediante un tablero Kanban en GitHub Projects
(*GineSalud - Tablero Kanban*), vinculado al repositorio. Cada historia de usuario (HU-01 a
HU-10) y cada tarea de elaboración del documento se registró como una tarjeta (*issue*) con
etiquetas por actor, prioridad y tipo de trabajo. Las tarjetas avanzan por las columnas
**Todo** (por hacer), **In Progress** (en progreso) y **Done** (hecho), lo que permite
visualizar el estado del backlog y la responsabilidad de cada integrante.
